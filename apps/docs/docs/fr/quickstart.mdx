## 1. Créer une clé

Connecte-toi, ouvre **Compte → Clés d’API** et choisis **Créer une clé**. Prends **Lecture et écriture** pour ce guide. Copie la clé : elle n’est affichée qu’une fois.

## 2. Lister tes projets

```bash
export API_KEY="tk_…"

curl https://example.com/api/v1/projects \
  -H "Authorization: Bearer $API_KEY"
```

```json
{ "data": [], "nextCursor": null }
```

## 3. Créer un projet

```bash
curl https://example.com/api/v1/projects \
  -H "Authorization: Bearer $API_KEY" \
  -H "Content-Type: application/json" \
  -d '{ "name": "Mon premier projet" }'
```

```json
{
  "id": "prj_4fQ9pX2mN7kL1sTz",
  "name": "Mon premier projet",
  "description": null,
  "createdAt": "2026-10-26T12:00:00.000Z",
  "updatedAt": "2026-10-26T12:00:00.000Z"
}
```

Le projet apparaît maintenant dans l’application, et un assistant IA connecté par [MCP](/mcp) le voit aussi.
