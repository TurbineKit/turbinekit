Chaque erreur a la même forme :

```json
{
  "error": {
    "type": "invalid_request_error",
    "code": "invalid_parameter",
    "message": "name: Too small: expected string to have >=1 characters",
    "param": "name"
  }
}
```

Branchez votre code sur `type` et `code` : ils ne changent pas. `message` s’adresse aux personnes et peut changer. `param` nomme le champ en cause, quand il y en a un.

| Statut | Type | Codes courants |
| --- | --- | --- |
| 400 | `invalid_request_error` | `invalid_parameter`, `invalid_json`, `invalid_cursor` |
| 401 | `authentication_error` | `missing_api_key`, `invalid_api_key` |
| 403 | `permission_error` | `insufficient_scope` |
| 404 | `not_found_error` | `resource_missing` |
| 413 | `invalid_request_error` | `body_too_large` |
| 429 | `rate_limit_error` | `rate_limited` |
| 500 | `api_error` | `api_error` |

## Autres codes

{/* #region turbinekit:orgs */}
- `403` `not_a_member` : la clé d’API agit pour une équipe dont vous ne faites plus partie.
{/* #endregion turbinekit:orgs */}
{/* #region turbinekit:admin */}
- `403` `account_banned` : un admin a banni le compte. Ses clés et ses jetons cessent de fonctionner.
{/* #endregion turbinekit:admin */}
{/* #region turbinekit:payments */}
- `403` `plan_limit_reached` : la limite du forfait est atteinte. Passez à un forfait supérieur, ou supprimez d’abord un élément.
{/* #endregion turbinekit:payments */}

{/* #endregion turbinekit:orgs|admin|payments */}

## Identifiants de requête

Chaque réponse a un en-tête `Request-Id` (`req_…`). Citez-le quand vous écrivez au soutien : il retrouve votre requête dans les journaux.
