---
title: Pagination
description: Les listes arrivent une page à la fois, avec un curseur vers la suivante.
sidebar:

---

Les points d’accès de liste renvoient une page de résultats et un curseur :

```json
{ "data": [ … ], "nextCursor": "MjAyNi0xMC0yNlQxMjowMDowMC4wMDBafHByal8…" }
```

Pour obtenir la page suivante, renvoie le curseur :

```bash
curl "https://example.com/api/v1/projects?limit=50&cursor=$NEXT_CURSOR" \
  -H "Authorization: Bearer $API_KEY"
```

`nextCursor` vaut `null` à la dernière page. `limit` vaut 20 par défaut et au plus 100. Traite le curseur comme opaque : son format peut changer.
