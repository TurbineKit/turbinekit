Der MCP-Server ist erreichbar unter:

```txt
https://example.com/mcp
```

Er verwendet den Streamable-HTTP-Transport und OAuth 2.1. Wenn sich ein Assistent verbindet, leitet er dich zur Anmeldung weiter, wo du genehmigst, was er darf. Die Tools, die er erhält, entsprechen den Berechtigungen, die du genehmigst: Ein Assistent, dem du nur Lesen erlaubst, sieht nur die Lese-Tools.

## Claude

Öffne in Claude **Anpassen**, lege einen benutzerdefinierten Connector an und füge die URL oben ein. Claude öffnet die Anmeldeseite; genehmige den Zugriff, und die Tools erscheinen im Chat. Die [Anleitung von Anthropic](https://support.claude.com/de/articles/11175166) zeigt jeden Schritt.

## Claude Code

```bash
claude mcp add --transport http my-app https://example.com/mcp
```

Führe `/mcp` in Claude Code aus, um dich anzumelden. Für ein Skript oder CI funktioniert statt OAuth auch ein API-Schlüssel:

```bash
claude mcp add --transport http my-app https://example.com/mcp \
  --header "Authorization: Bearer $API_KEY"
```

## Cursor

Füge den Server zu `.cursor/mcp.json` hinzu:

```json
{
  "mcpServers": {
    "my-app": { "url": "https://example.com/mcp" }
  }
}
```

## ChatGPT

Öffne in ChatGPT die Seite [Plugins](https://chatgpt.com/plugins), lege einen benutzerdefinierten MCP-Server an und füge die URL oben als Server-URL ein. Erstelle dann das Plugin und installiere es. Die [Anleitung von OpenAI](https://developers.openai.com/api/docs/guides/custom-mcp-server) (auf Englisch) zeigt jeden Schritt.

## Tools

| Tool | Berechtigung | Was es tut |
| --- | --- | --- |
| `list_projects` | `projects:read` | Listet deine Projekte auf, die neuesten zuerst |
| `get_project` | `projects:read` | Gibt ein Projekt zurück |
| `create_project` | `projects:write` | Erstellt ein Projekt |
| `update_project` | `projects:write` | Benennt ein Projekt um oder ändert seine Beschreibung |
| `delete_project` | `projects:write` | Löscht ein Projekt (der Assistent fragt vorher nach) |

Jedes Tool ist dieselbe Operation wie sein REST-Endpunkt, mit denselben Regeln und Fehlern.
