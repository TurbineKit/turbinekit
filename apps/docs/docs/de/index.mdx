Über die API arbeiten dein Code und deine KI-Assistenten mit denselben Daten, die auch in der App zu sehen sind. Sie bietet zwei Zugänge zu denselben Operationen:

- **Die REST-API** unter `https://example.com/api/v1`, für Skripte, Backends und Integrationen. Sie spricht JSON; die Authentifizierung erfolgt mit einem API-Schlüssel.
- **Der MCP-Server** unter `https://example.com/mcp`, für KI-Assistenten wie Claude, ChatGPT und Cursor. Die Anmeldung läuft über OAuth, und dabei wird festgelegt, was der Assistent darf.

Beide führen dieselben Operationen mit denselben Regeln aus: Ein Projekt, das über den einen Zugang erstellt wird, erscheint auch im anderen und in der App.
