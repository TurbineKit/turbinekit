## 1. Schlüssel erstellen

Melde dich an, öffne **Konto → API-Schlüssel** und wähle **Schlüssel erstellen** aus. Stelle für diese Anleitung **Lesen und schreiben** ein. Kopiere den Schlüssel: Er wird nur einmal angezeigt.

## 2. Projekte auflisten

```bash
export API_KEY="tk_…"

curl https://example.com/api/v1/projects \
  -H "Authorization: Bearer $API_KEY"
```

```json
{ "data": [], "nextCursor": null }
```

## 3. Projekt erstellen

```bash
curl https://example.com/api/v1/projects \
  -H "Authorization: Bearer $API_KEY" \
  -H "Content-Type: application/json" \
  -d '{ "name": "Mein erstes Projekt" }'
```

```json
{
  "id": "prj_4fQ9pX2mN7kL1sTz",
  "name": "Mein erstes Projekt",
  "description": null,
  "createdAt": "2026-10-26T12:00:00.000Z",
  "updatedAt": "2026-10-26T12:00:00.000Z"
}
```

Das Projekt erscheint jetzt in der App, und ein über [MCP](/mcp) verbundener KI-Assistent sieht es ebenfalls.
