The MCP server is at:

```txt
https://example.com/mcp
```

It uses the Streamable HTTP transport and OAuth 2.1. When an assistant connects, it sends you to sign in and to approve what it may do. The tools it gets match the permissions you approve: an assistant you allow to read sees only the read tools.

## Claude

In Claude, open **Settings → Connectors → Add custom connector**, and paste the URL above. Claude opens the sign-in page; approve the access, and the tools appear in the chat.

## Claude Code

```bash
claude mcp add --transport http my-app https://example.com/mcp
```

Run `/mcp` in Claude Code to sign in. For a script or CI, an API key works instead of OAuth:

```bash
claude mcp add --transport http my-app https://example.com/mcp \
  --header "Authorization: Bearer $API_KEY"
```

## Cursor

Add the server to `.cursor/mcp.json`:

```json
{
  "mcpServers": {
    "my-app": { "url": "https://example.com/mcp" }
  }
}
```

## ChatGPT

In ChatGPT, open **Settings → Apps and connectors → Advanced**, turn on developer mode, then create a connector with the URL above.

## Tools

| Tool | Permission | What it does |
| --- | --- | --- |
| `list_projects` | `projects:read` | Lists your projects, newest first |
| `get_project` | `projects:read` | Returns one project |
| `create_project` | `projects:write` | Creates a project |
| `update_project` | `projects:write` | Renames a project or changes its description |
| `delete_project` | `projects:write` | Deletes a project (the assistant asks first) |

Each tool is the same operation as its REST endpoint, with the same rules and errors.
